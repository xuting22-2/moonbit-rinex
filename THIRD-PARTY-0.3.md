# Sources and third-party materials for0.3.0
Project implementation is original MoonBit format/state/math code under rootMIT, not a foreign binary wrapper. Standard mathematical formulae are not claimed as new algorithms.

- IGS RINEX2.11 (2007/2012), https://files.igs.org/pub/data/format/rinex211.txt ;3.04, https://files.igs.org/pub/data/format/rinex304.pdf ;3.05, https://files.igs.org/pub/data/format/rinex305.pdf : fixed fields, time systems, observation signals and NAV layout.
- IS-GPS-200N, https://archive.gps.gov/technical/icwg/IS-GPS-200N.pdf : LNAV clock/orbit equations. Selected version cover2022-08-01; no physical-accuracy assertion.
- Hatanaka,Y.(2008), A Compression Format and Tools for GNSS Observation Data, Bulletin ofGSI55,21–30, https://www.gsi.go.jp/common/000045517.pdf . Numeric/text series and versioned initialization. The package has its ownLICENSE, GSI-terms exception and citation requirements, notMIT. Official output rendering and line differences are documented in its RNXCMP.txt.
- RTKLIB source inspected at71db0ffa0d9735697c6adfd06fdf766d0e5ce807, https://github.com/tomojitakasu/RTKLIB/tree/71db0ffa0d9735697c6adfd06fdf766d0e5ce807 .
