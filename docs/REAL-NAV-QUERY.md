# 从真实 BRDC 文件查询并核对来源

`tools/nav-query.mjs` 可为指定卫星和时刻查询一份 GPS/BDS 广播星历目录。下面的结果来自本地缓存的同一份 BKG/IGS 输入，用于说明完整文件加载、查询状态和来源核对。选择规则见 [目录契约](NAV-CATALOG-0.4.md)。

## 输入身份

数据提供者：IGS 及其贡献分析中心，经 BKG 提供；[原始 gzip 文件](https://igs.bkg.bund.de/root_ftp/IGS/BRDC/2026/299/BRDC00WRD_R_20262990000_01D_MN.rnx.gz)。文件名中的 2026 年第 299 天为 10 月 26 日，文件内也包含前一日的记录。它是 RINEX 3.05 混合星座 NAV 输入。

| 项目 | 缓存值 |
|---|---|
| gzip 字节数 | 1287481 |
| gzip SHA256 | `17d903b3a7082296966b538f1abe03188a2bbca121df0a144895820988f9fe5f` |
| 解压后字节数 | 9760898 |
| 解压后 SHA256 | `a0810bad8bd99029c0f2971e1bdd9032a82746ffe4b9ae15921db0424f0558b9` |
| 物理行数 / 头行数 | 120505 / 70 |
| GPS / BDS 记录数 | 426 / 1035 |
| 其他星座记录数 | 20134 |

原始外部数据与参考运行库未打包进源码。数据许可和署名沿用 [第三方说明](../THIRD-PARTY-0.4.md)，不将外部数据默认视为 MIT。上述身份描述缓存字节；远端文件若更新，应重新核对身份。

## 运行

准备与上述 SHA256 一致的解压文件，在项目根目录执行：

```sh
moon build --target js --release --deny-warn
node tools/nav-query.mjs BRDC00WRD_R_20262990000_01D_MN.rnx G01 2442 50400 --skip-unsupported
node tools/nav-query.mjs BRDC00WRD_R_20262990000_01D_MN.rnx C06 1086 72000 --bdt --meo-igso --skip-unsupported
node tools/nav-query.mjs BRDC00WRD_R_20262990000_01D_MN.rnx C06 1086 0 --bdt --meo-igso --skip-unsupported
```

CLI 接受普通 ASCII 文件，需要先解压 `.gz`。默认容量 4096 可容纳本文件的 1461 条受支持记录。混合文件中有其他星座，需显式传入 `--skip-unsupported`；跳过只消费已知长度并计数，不验证那些记录的数值。

三次加载的 stderr 回执均为 `complete: true`、`stored_records: 1461`、`skipped_unsupported: 20134`、`lines: 120505`、`bytes: 9760898`。受支持记录数另以原始物理行的记录起始标记独立计数核对。`complete` 表示此加载范围内成功结束，不表示其他星座或整文件物理质量已获认证。

## 空目录与文件末尾

`complete: true` 与 `selected` 是两个判断。仅有合法 NAV 头的输入可完成加载，目录保存 0 条记录，查询返回退出码 2 / `unavailable`，候选数为 0。显式跳过一条完整 Galileo 记录的输入也返回同样的空目录状态，并在回执中保留 `skipped_unsupported: 1`。这表示配置范围内没有受支持记录可供查询，不表示 Galileo 的数值已获校验。

跳过记录仍须完整：一条可用 GPS 记录后，若 RINEX 3.05 GLONASS 五行记录缺少最后一行，或 Galileo 八行记录缺少最后一行，CLI 在 finish 时退出 1，回执为 `complete: false`，stdout 为空。此前保存的 GPS 记录不能将截断文件变成成功结果。这两条记录分别取自相同缓存文件的 R01 / E02，只为明确错误路径删除最后一行。

另将该缓存文件的 G02、G01 原始数值字段按顺序转换为两条 NAV2.11 记录，独立 RTKLIB 读取 2 条并在各自 Toe 评价；转换前后的对应状态一致。实际 CLI 分别选择 G02 的索引 1 / 来源行 3，以及 G01 的索引 2 / 来源行 11，候选数各为 1。坐标和钟差均在上述同模型阈值内，说明第二条记录及不同卫星分组的来源仍可追溯；这些转换输入不称为原生 NAV2 采集数据。
